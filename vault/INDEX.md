# Vault Index

The vault is the repository source of truth for durable source material, analysis, canonical knowledge, decisions, and superseded material.

## Structure

- `inbox/raw/`: Append-only raw captures exactly as provided, with minimal metadata headers.
- `sources/`: Curated supporting source material.
- `analysis/`: Interpretations, deductions, contradictions, and candidate canonical changes.
- `canonical/`: Approved current architecture, language, and operating knowledge.
- `decisions/`: Dated records explaining what changed and why.
- `superseded/`: Material no longer current but intentionally preserved.
